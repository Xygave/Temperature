# Temperature — Paper 1.21.11

Плагин без клиентских модов. Java 21, Maven, Paper 1.21.11.

## Сборка через GitHub
1. Создай **пустой** репозиторий на GitHub.
2. Загрузи **содержимое** папки TemperaturePlugin в корень репозитория (важно: `.github/workflows/build.yml` должен лежать именно в корне).
3. Открой **Actions → Build Temperature → Run workflow** (или дождись сборки после push).
4. Открой успешный запуск, скачай **Temperature-jar** из **Artifacts**, распакуй ZIP.
5. Положи `Temperature-1.0.0.jar` в папку `plugins` сервера Paper и перезапусти сервер.
6. Появится `plugins/Temperature/config.yml`. Редактируй настройки, затем используй `/temperature reload`.

## Как работает
- На холоде: первая стадия — ледяная рамка, вторая — Slowness I, третья — периодический урон.
- Полный комплект кожи полностью защищает. Незерит увеличивает время до стадий пропорционально количеству предметов.
- Любое ванильное рагу защищает на заданное время. Огонь, лава, костер, факел защищают, пока рядом.
- В Аду через 1 минуту Slowness I. В пустыне днем или рядом с огнем/лавой в обычном мире — через 3 минуты.
- Бутылка воды/любое зелье снимает жару и защищает временно; вода также защищает.
- Температура отображается 5 секунд при входе, смене биома, каждые 5 минут.
- Никаких постоянных HUD, вычисления температуры тела, лучей солнечного света.

## Ограничения и детали
- Плагин не меняет реальные механики погоды Minecraft и показывает условные температуры биомов.
- При выходе из опасной зоны счетчик обнуляется. При перезаходе счетчик начинается заново.
- Изменение дня на ночь меняет пороги замерзания сразу, но уже накопленное время сохраняется.
- В холодных биомах рядом с лавой холод блокируется, но в обычном мире сама лава может вызвать жару.
- Отображение названий биомов пока использует технические английские имена, без русской локализации.
- Система замерзания использует встроенный frost-overlay Minecraft. Если игрок находится в рыхлом снегу, ванильная механика снега имеет приоритет.
- Для эффекта Slowness плагин старается не перезаписывать чужие эффекты, но одновременные эффекты других плагинов требуют проверки на тестовом сервере.
